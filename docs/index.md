# Documentation

The documentation is organized by topic. General guides describe the latest
code, while research protocols are frozen under explicit RQ and version paths.

- `getting-started/`: installation and first execution
- `architecture/`: pipeline and artifact lifecycle
- `protocols/`: versioned RQ1–RQ3 methods
- `data/`: dataset policy, manifests, and sampling
- `models/`: model adapter and backend conventions
- `metrics/`: metric definitions and aggregation
- `reproducibility/`: environment and run identity
- `contributing/`: development and result submission
- `reference/`: CLI, configuration, schemas, and glossary
